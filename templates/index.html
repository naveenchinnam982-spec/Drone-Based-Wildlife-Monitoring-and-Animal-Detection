About Project

Technical details, AI architecture, and dataset specifications

Drone-Based Wildlife Monitoring & Animal Detection

An automated computer vision system designed for monitoring wildlife habitats and counting wild animal populations using aerial unmanned aerial vehicle (UAV) imagery.

System Functionality & Workflow

The application runs real-time inference using a customized YOLO11s (You Only Look Once v11 small) deep neural network. Uploaded drone images are resized and evaluated by the neural network to identify target bounding boxes, assign class probabilities, and compute aggregate counts.
